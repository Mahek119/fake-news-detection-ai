# Fake News Detection AI

An end-to-end fake news detection system using BERT, NLP, FastAPI, and Spring Boot to classify news articles as REAL or FAKE using writing style analysis and live evidence retrieval.

---

## Features

- Fine-tuned BERT model for fake news classification
- Sentence-BERT semantic similarity scoring
- Live evidence retrieval from trusted news sources
- Confidence-based REAL/FAKE prediction engine
- Interactive frontend visualizations
- Full-stack architecture with FastAPI + Spring Boot
